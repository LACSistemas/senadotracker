## Reprodução

Configure as variáveis descritas em `.env.example` e execute:

```bash
npm run db:migrate:postgres
```

O comando recria somente o schema configurado em `DB_SCHEMA`. Qualquer falha executa rollback. Nenhuma senha é gravada no relatório.

## Estado do runtime

O PostgreSQL contém a cópia integral e validada. A aplicação continua lendo o SQLite durante a refatoração do acesso síncrono para o driver assíncrono `pg`. A troca de tráfego só deve ocorrer depois que frontend e coletor tiverem consultas PostgreSQL equivalentes e um usuário exclusivo de leitura para o frontend.
