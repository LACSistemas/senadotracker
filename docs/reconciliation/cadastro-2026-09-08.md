## Como reproduzir e conferir

```sh
npm run collector -- collect --source all
npm run collector -- status
```

A coleta exige internet. `status` lê somente o banco local. Repetir a coleta cria novo lote auditável, reutiliza as mesmas pessoas pelos IDs oficiais, mantém lotes anteriores e troca o ponteiro ativo somente após reconciliação e publicação transacional.
