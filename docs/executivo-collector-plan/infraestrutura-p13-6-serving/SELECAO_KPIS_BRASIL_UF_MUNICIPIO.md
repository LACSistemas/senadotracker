# Seleção editorial

A visão geral retorna até oito indicadores com valor observado, unidade, período, fonte, status e cobertura. Para Brasil/UF a seleção usa linhas diretas da entidade; para município usa dados diretos do município. O catálogo completo permanece acessível via `getInfrastructureIndicators`. Um município sem valor elegível recebe menos KPIs, nunca zero sintético.
