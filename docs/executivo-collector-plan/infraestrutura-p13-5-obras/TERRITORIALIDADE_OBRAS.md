# Territorialidade

O projeto traz `uf_principal`; o piloto cobriu as 27 UFs. O recurso de geometria traz `cod_ibge`, município e UF, mas as 200 geometrias amostradas não tinham pai entre os 200 projetos amostrados (rejeitadas por integridade referencial). Os `pins` aninhados dos projetos foram observados, mas não foram materializados nesta primeira publicação.

Consequentemente, `projects_with_valid_location=0`, `multi_territorial_projects=0` e `unverified_links_published=0` no piloto. Isso é uma limitação de amostragem, não ausência nacional de territorialidade.
