# Moradia e condições domiciliares

Censo 2022/SIDRA oferece tipo/condição de ocupação, moradores por domicílio, densidade, aluguel, banheiro/sanitário, esgotamento, água, lixo, máquina de lavar, internet e rendimento. Município é granularidade comprovada; área de ponderação só entra após revisão de disclosure.

Déficit habitacional municipal não será inferido de taxa estadual. Domicílio, família e pessoa permanecem unidades distintas.
