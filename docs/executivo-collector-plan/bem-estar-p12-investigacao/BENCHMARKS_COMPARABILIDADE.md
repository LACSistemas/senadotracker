# Benchmarks e comparabilidade

Alinhar ano, unidade, denominador, universo, fonte e método. Comparações recomendadas: município × própria série; município × UF; município × Brasil; mediana de municípios da mesma UF; faixa de porte por população, apenas para o mesmo indicador e ano.

Mediana municipal não é mediana das pessoas; média estadual não é média simples das cidades; saldo formal não é desemprego; famílias beneficiárias não são proporção de pessoas pobres. Rankings nacionais ficam bloqueados quando `ranking_allowed=false`, cobertura é parcial ou denominadores não equivalem.
