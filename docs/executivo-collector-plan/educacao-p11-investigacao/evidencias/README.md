# Evidências P11

Esta pasta contém somente provas da investigação: inventário local, prova de banco, URLs oficiais, tentativas de acesso e referências ao P10. Nenhum RAW grande foi baixado para o repositório.

- repo_inventory.json: documentos e tabelas existentes reutilizáveis.
- db_identity_probe.json: resultado de SELECT current_database() e contagem territorial.
- official_sources.json: fontes oficiais e fatos observados.
- access_probe.json: acessos e limitações de rede da rodada.
