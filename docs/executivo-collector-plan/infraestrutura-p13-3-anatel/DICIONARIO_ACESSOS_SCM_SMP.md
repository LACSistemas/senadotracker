# Dicionário SCM/SMP

O glossário oficial do SCM e a página oficial de coleta definem arquivos CSV, competência mensal e granularidade municipal. O campo semântico de acesso não é população coberta: representa acessos/assinaturas reportados pelas prestadoras. Para SMP, acessos, ERBs e cobertura são dimensões distintas e não devem ser somados.

Nesta execução não houve CSV estruturado disponível para validar nomes, tipos e chaves de coluna. Logo, nenhum indicador SCM/SMP foi publicado.
