# Dicionário IQS/Selos

Segundo as páginas oficiais da Anatel, o IQS é municipal, estadual e nacional; os resultados têm periodicidade semestral/anual conforme indicador. O IQS/Selo usa escala de 0 a 100, maior é melhor. Agregados UF/Brasil usam ponderação por acessos quando a metodologia assim determina; não foi feita média simples de municípios.

O catálogo oficial foi localizado, mas a planilha/dicionário estruturado não pôde ser recuperado neste ambiente. Campos e indicadores permanecem documentados, não publicados.
