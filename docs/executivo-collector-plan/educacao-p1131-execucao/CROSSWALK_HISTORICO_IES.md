# Crosswalk historico de IES

O vinculo usa exclusivamente `CO_IES` exato contra o cadastro do Censo Superior persistido. Nenhum nome foi usado para completar lacunas.

Linhas IGC sem correspondencia no cadastro operacional: **431**. Antes de 2022 foram classificadas como `HISTORICAL_OUTSIDE_CENSO_WINDOW`; 2022/2023 como `NOT_IN_OPERATIONAL_CENSO_WINDOW`. Essas classificacoes nao provam encerramento, fusao ou mudanca de codigo.
