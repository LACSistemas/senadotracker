# Identidade e crosswalk

IGC usa `CO_IES`. CPC/Enade/IDD usam `CO_IES + CO_CURSO + município + área` como chave source-native. O vínculo com P11.2 é por códigos oficiais; não há fuzzy nem associação por nome. Estados: `OFFICIAL_LINK`, `UNRESOLVED`, `AMBIGUOUS`, `NOT_APPLICABLE`, `NEEDS_VALIDATION`. Os não resolvidos permanecem no fato bruto agregado.
