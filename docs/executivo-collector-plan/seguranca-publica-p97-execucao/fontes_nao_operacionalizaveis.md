# Fontes e frentes não operacionalizadas (P9.7)

| Frente | Fonte | Classificação | Por que não virou indicador |
|---|---|---|---|
| Operações policiais | PF (estatísticas), SSPs | DISCOVERY_ONLY | sem série oficial estruturada com unidade de evento, regra de duplicação e reconciliador; só notícias e balanços |
| Operações — DAMAZ/PF 2024 | `dados-operacionais-damaz-em-2024.xlsx` (SIGACrim) | AGGREGATES_ONLY | um ano; escopo ambiental/Amazônia Legal; não é o universo de crime organizado |
| Estatísticas de polícia judiciária | PF EPOL (dados.gov.br) | DISCOVERY_ONLY | a página exige JavaScript, a API pública pede token (401), a documentação só cita painel eleitoral |
| Apreensão federal de drogas/armas | PF/PRF | DISCOVERY_ONLY | não há arquivo aberto localizado; o que existe de PF/PRF por UF já está no VDE (abrangência PF/PRF) |
| Registros de armas | SINARM/CAC | NOT_SUITABLE | posse/porte/CAC não são armas apreendidas |
| Criminalidade financeira | COAF | DISCOVERY_ONLY | totais nacionais em relatório anual (PDF), sem recorte por UF; RIF não é crime; uso em debate no STF (Tema 1.404) |
| Condenações / procedimentos | CNJ DataJud | DISCOVERY_ONLY (não testado) | API com chave, nível de processo, sem mapeamento comprovado para crime organizado/tráfico |
| Processos por tráfico | MJSP/Senad/Ipea (painel 2024) | NOT_SUITABLE | amostra de ~5 mil processos de 2019, nível de processo |
| Organizações criminosas por território | SENAPPEN Mapa Orcrim | NOT_SUITABLE_FOR_PUBLICATION | versão completa sigilosa; só resumo (88 organizações; 1.760 pavilhões); **nenhuma** atribuição territorial |
| Vulnerabilidade a crime organizado | IVCO — OBID/UNODC/CDESC (2026, 146 p.) | NOT_SUITABLE_FOR_PUBLICATION | índice por Terra Indígena, composto, não é registro de atividade nem município/UF |
| Uso/porte por município | SSP-BA (acumulado jan–set/2026) | AGGREGATES_ONLY | sem mês; universo é uso/porte; sem série |
