# Auditoria TP_DIMENSAO/EAD

A chave que inclui `tp_dimensao` elimina as colisões da chave antiga. Grupos repetidos sem essa dimensão foram 396 (2022), 461 (2023) e 452 (2024): dimensão é parte da identidade source-native.

Em 2024, 708.580 linhas (10.224.727 matrículas) são dimensões 1/2 e 11.769 linhas (2.539 matrículas) dimensões 3/4. A soma nacional mantém as duas partições; serving municipal/UF só usa geografia observada. Nenhuma linha territorial tem município não resolvido.

O dicionário de cada edição é a autoridade para exclusividade semântica; por isso o gate é `PASS_WITH_CAVEATS`.
