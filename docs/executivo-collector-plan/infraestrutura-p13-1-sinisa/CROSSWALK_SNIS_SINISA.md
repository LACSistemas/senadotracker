# Crosswalk SNIS → SINISA

O SNIS encerrou a coleta e o SINISA iniciou nova operação. Nomes semelhantes não bastam para série contínua. Para cada par futuro, o crosswalk deve conter `SNIS_CODE`, `SINISA_CODE`, equivalência semântica, equivalência de fórmula, equivalência de universo, comparabilidade temporal e `REQUIRES_BREAK`.

Estado desta execução: **nenhum par validado**. O Projeto ACERTAR é referência documental, não prova automática. Até leitura dos dicionários, toda série SNIS–SINISA é interrompida (`TIME_SERIES_COMPARABLE=UNKNOWN`).
