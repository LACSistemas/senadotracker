# Dicionario STJ e identidades

Os dicionarios oficiais de Temas, Processos, Espelhos e Integras de decisoes foram baixados e registrados como snapshots. As chaves usadas sao: `sequencialPrecedente` para precedente; `sequencialPrecedente + numeroRegistro + Processo` para processo; `id` para espelho; `SeqDocumento` para decisao.

Nao ha CPF, matricula ou ID nacional de ministro nos datasets usados. Orgaos e relatores sao preservados como nomes source-native; nao sao tratados como identidade civil global.
