# Painéis CNJ e temas

Fonte: [Painéis CNJ](https://www.cnj.jus.br/paineis-cnj/). A página lista Justiça em Números, DataJud, MPM/Dados de Pessoal, Grandes Litigantes, sustentabilidade e outros painéis Qlik.

## Estados de acesso

- JN: relatório e base estruturada confirmados em P2; painel é camada de consulta.
- DataJud Estatística: iframe/painel, sem bulk comprovado.
- MPM/Dados de Pessoal: público agregado por tribunal, estado ou ramo; o módulo operacional recebe cadastro pessoal internamente.
- Grandes Litigantes: apresenta maiores litigantes por tribunal/unidade, mas não substitui uma base nacional aberta de partes.
- Temas: painéis são documentação/visualização até que endpoint ou arquivo estruturado seja comprovado.

Não tratar Qlik como API pública sem verificar licença, chamadas e estabilidade. Para o MVP, importar JN estruturado e registrar links de painéis como método/explicação.
