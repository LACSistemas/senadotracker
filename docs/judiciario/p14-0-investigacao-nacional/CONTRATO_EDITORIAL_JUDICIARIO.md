# Contrato editorial do Judiciário

## Promessa

Explicar como a Justiça se organiza, qual demanda recebe, quanto custa e quais resultados institucionais são medidos, com fonte, ano-base, denominador e cobertura visíveis.

## Navegação conceitual

`/judiciario` (panorama) → `/judiciario/tribunais` → perfil de tribunal → unidade/território quando comprovado → jurisprudência STJ como vertical. Seções: visão geral, demanda, tempo, estrutura, finanças, decisões, fontes e metodologia.

## Regras de linguagem

“Processos julgados” não significa decisões corretas; “taxa de congestionamento” não é tempo individual; “localizado em” não significa “atende somente”; “relator” não significa autor único do voto. Não usar ranking de magistrados ou inferência de culpa.

## Disclosure

Cada métrica mostra fonte, edição, data de extração, cobertura e estado (`disponível`, `parcial`, `não comparável`, `bloqueado`). Null não vira zero. Dados pessoais só aparecem com finalidade e licença explícitas.
